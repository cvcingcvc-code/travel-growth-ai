# 用户操作指南 — TravelGrowth AI

## 1. 切换与创建企业工作空间
顶部导航栏右侧可随时切换当前企业，或点击“新建企业”创建独立工作空间（例如“松间隐庐民宿”或“青城山居景区”）。不同企业之间的知识库、素材、选题与草稿完全隔离。

## 2. 录入产品与企业知识
- 在**企业知识库**中按 A~F 六大分类录入或导入 Markdown/TXT/CSV 文件。
- 涉及价格、地址、营业时间、活动政策的内容，请务必确认后标记为“已核实”；未核实内容会在 AI 创作时触发提醒。

## 3. 从市场情报到内容创作
1. 在**市场情报中心**手动录入、或通过公开 URL / RSS / CSV 导入行业动态。
2. 将高价值案例转入**爆款分析中心**，生成 11 维结构化分析并保存为**营销策略卡片**。
3. 进入**AI 内容创作中心**，选择产品、目标平台、风格与参考策略，一键生成选题、多标题、正文、多页图文方案及知识引用。
4. 在右侧大尺寸预览区直接编辑文案并**保存草稿**，审核通过后记录发布数据。

## 4. 模型配置说明
进入**模型配置中心**可查看当前文本/视觉/生图/Embedding 模型状态。若尚未配置真实 API Key，系统会明确提示“未配置”，并提供可标记的**测试模式**用于验证完整工作流闭环。
