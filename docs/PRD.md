# 产品需求文档 (PRD) — TravelGrowth AI

## 1. 产品背景与定位
TravelGrowth AI 面向景区、民宿、旅游企业及文化传播机构，提供从市场情报采集到内容复盘沉淀的全链路 AI 内容营销工作台。系统强调**企业工作空间隔离**、**真实事实核查（防幻觉）**、**人工审核兜底**与**外部智能体可接管性**。

## 2. 第一阶段（P0）核心功能范围
1. **今日工作台**：今日市场情报、新增热点、潜力选题、创作任务、待审核内容、知识库状态、系统任务状态与快捷入口。
2. **市场情报中心**：手动录入、URL 导入、RSS 与合规公开数据源、CSV 导入、关键词与来源管理、去重与筛选、预留未授权平台适配器（小红书/抖音/微信公众号，明确标注未接通）。
3. **爆款分析中心**：11 维结构化拆解（标题钩子、目标客群、用户痛点、内容结构、情绪价值、视觉风格、产品卖点、转化方式、可复用策略、企业匹配度、证据来源与可信度），支持保存为营销策略卡片。
4. **企业知识库**：6 大分类（A.基本事实、B.产品服务、C.品牌客群、D.案例策略、E.历史经验、F.系统与Agent规范），支持 Markdown/TXT/CSV 导入（预留 PDF/DOCX 接口）、版本管理、关键词+向量检索、未核实事实标注。
5. **AI 内容创作中心**：基于企业/产品/平台/客群/目的/风格/参考案例生成选题、多标题、正文、封面设计说明、多页图文方案、生图提示词、话题标签、转化引导、知识引用与内容风险检查；支持编辑、版本保存、复制与导出。
6. **素材管理中心**：管理实景照片、AI 概念图、品牌海报与文档，强制记录版权状态与来源，严禁将 AI 概念图标记为真实实景。
7. **模型配置中心**：统一 Text / Vision / Image / Embedding Provider 接口，支持 OpenAI、Gemini、Claude、DeepSeek、Ollama 及 OpenAI-compatible，记录 `model_runs`。
8. **开放接口与帮助中心**：版本化 REST API、OpenAPI 3.1 文档、MCP 工具端点与站内帮助中心。

## 3. 非功能性需求
- 数据持久化：SQLite（本地零依赖可迁移至 Postgres）。
- 多租户隔离：`organization_id` 贯穿数据库、服务层、API、检索与素材。
- 安全与合规：默认禁止自动发布，不可信输入隔离，密钥不入库。
