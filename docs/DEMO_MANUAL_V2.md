# TravelGrowth AI 2.0 — 企业客户现场演示手册与交付清单

## 一、下午客户演示 6 分钟黄金动线

1. **新企业 6 步入驻向导（0:00–1:00）**
   - 点击右上角 **「+ 企业入驻」**，演示 6 步流程：基础信息 → 导入资料（TXT/MD/CSV，明确标注 PDF/DOCX 未接通） → 自动提取品牌定位与禁区 → 知识库预览确认 → 建立产品档案 → 确认营销方向并自动创建专属营销 Agent。
2. **企业专属 Agent 编排可视化（1:00–2:15）**
   - 进入左侧 **「专属 Agent」**，展示 8 大逻辑角色与企业持久化配置；点击 **「运行总控 Agent 诊断」**，实时展示 4 步真实工具调用（输入摘要、输出结果、耗时与重试入口）。
3. **市场情报与同行爆款分析（2:15–3:00）**
   - 切换企业至 **「山海拾光文旅（虚构演示企业）」**，进入 **「市场情报」** 展示 B01–B03 公开对标案例、11 维结构化拆解与策略卡片（强调不编造未获取的互动量）。
4. **自动营销方案（3:00–3:45）**
   - 进入 **「营销方案」**，点击 **「生成完整营销方案」**，展示 7 天/30 天计划、选题库、差异化卖点与待核实提醒，点击 **「审批通过」**（版本自动递增）。
5. **内容生产、真实概念封面与发布中心 ZIP（3:45–5:00）**
   - 进入 **「内容生产」** 展示 D01–D03 的 3:4 封面图与 6 页分镜预览；再进入 **「发布中心」** 演示 **一键复制文案**、**导出 ZIP 发布包（含 `copy.txt` + `metadata.json` + 配图）**、人工审核与 **确认已人工发布并建档**。
6. **数据复盘与知识回流（5:00–6:00）**
   - 进入 **「数据复盘」**，登记社媒账号、录入标明来源的数据快照，点击 **「运行数据复盘 Agent」**（样本 < 3 自动提示统计边界），点击 **「审核并回流企业知识库」** 完成闭环。

## 二、已实现能力、未接通能力与风险清单

### 已实现并验证
- Linear/飞书风格浅色深蓝 10 模块可折叠工作台、全局搜索、消息通知、Agent 状态栏。
- 6 步企业入驻向导、24 张 SQLite 数据表持久化与严格 `organization_id` 隔离。
- 自动生成持久化专属 Agent、统一 Orchestrator 8 角色调度与真实执行步骤日志。
- 自动营销方案（7天/30天计划、审批、版本）、内容生产、一键复制与真实 PKZIP 发布包导出。
- 社媒账号管理、发布记录、标明来源的指标录入、复盘洞察与知识库回流。

### 未接通能力（绝不伪造）
- 小红书/抖音/公众号/视频号官方自动抓取与自动发布（保持 `manual_only` / `not_connected`）。
- PDF / DOCX 解析器（仅预留，当前支持 TXT / Markdown / CSV）。
- 网页端实时调用付费生图 API（未配置外部生图密钥时走导出生图提示词 + 上传外部图）。
- `/api/mcp` 为自定义 HTTP JSON 工具接口，非标准 JSON-RPC 2.0 MCP Server。

### 生产上线风险提示
- **Vercel 持久化风险**：Vercel Serverless 下 SQLite 位于 `/tmp`，冷启动会重置；正式客户生产环境必须切换至外部持久化数据库（Neon / Turso / Postgres）与对象存储（Vercel Blob / R2）。
