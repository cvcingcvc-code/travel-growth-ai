# 安全与企业隔离规范 — TravelGrowth AI

1. **多租户隔离**：所有业务表均含 `organization_id`，服务端通过 `requireOrgAccess(orgId)` 校验企业存在性及调用方权限，严禁跨企业读取或写入。
2. **不可信数据防御**：外部 URL、RSS、CSV、Markdown 导入内容及市场案例正文在传入 AI Prompt 前，均封装在明确的数据边界标记中，并附带防注入系统指令，禁止将其作为系统指令执行。
3. **防幻觉与真实性约束**：
   - 未经确认的价格、地址、营业时间、政策必须标注 `[待核实]`。
   - 未授权平台（小红书、抖音、微信）适配器明确返回 `not_connected`。
   - AI 概念图强制标记 `is_ai_generated = 1`，不可冒充实景照片。
4. **高风险操作审计**：创建/删除知识库重要文档、发布状态变更、模型密钥变更等操作均写入 `audit_logs`。
5. **密钥安全**：所有密钥仅通过环境变量或本地未入库配置读取，前端仅显示脱敏状态。
